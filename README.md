One line of brutally honest error copy: saving failed because the disk is full, so the user's unsaved work is still floating in memory — and it tells them exactly what to do next (delete something old, save again) before memory forgets it. Running `main.py` writes that single line to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
